Although I'm often hesitant to use AI, I found ChatGPT to be quite helpful for this project. Firstly, it helped me narrow the scope of the project. I originally wanted to use TKinter to add a visual component, including a gameboard with separate rooms, a rolling dice/moving component, and possibly an automated opponent. After putting my idea list/outline into ChatGPT (as, here is my outline for this project [], help me make a timeline/checkpoints for it), I realized that a much simpler game might yield a comparable result. I decided to go the text-based route, so I could focus on my code, rather than worrying about the GUI. Using ChatGPT during the planning phase also helped keep me organized. Because I had the full scope of what I wanted, it was easy for me to break things into pieces. Rather than having everything in one file (like I am wont to do...), I could follow my outline, putting each "game piece" in its own file. That was also very helpful for debugging - rather than scrolling through hundreds of lines of code in one file, I had only a few dozen in any given, discrete file to look through. In addition to being helpful during the planning stage, I used ChatGPT as a debugger. This was not just when I had actual bugs, but when I got results that I wasn't expecting. Having ChatGPT "read" my code to pinpoint problem spots helped me understand issues in my logic that I hadn't noticed because, well, I knew what I meant when I wrote it. One example of this was right after I finished the main "check accusation" logic. I added in a debugging print statement to display the game's solution, so I could check that the correct answer would end the game. When I tried it out, the correct answer was not accepted. I pasted the code into ChatGPT, asking why the correct input didn't end the game. It responded with a simple fix - I just needed to get rid of the leading spaces in the user's input. Normalizing the text was actually something I had thought about - I had made sure that the solution was case insensitive, but I had forgotten about spaces. In another instance, I wanted to ensure that my game would not continue infinitely, so I put a break below a line of code that would run if the player made an incorrect final accusation. However, I put the break line in the game (class) logic, not the main (gameplay) logic - so it was outside of a loop and threw up errors. ChatGPT caught that as well, and I was able to add in a "game over" condition to trigger the break inside of the actual gameplay loop, instead. While AI proved to be a very useful tool in this project, I was also very grateful for the experience of a senior programmer (my wonderful dad), who helped me iron out the note-taking aspect of the game, which I initially had some trouble with conceptualizing.
